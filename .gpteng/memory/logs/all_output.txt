# Node.js Backend with TypeScript

This project is a Node.js backend using TypeScript that replicates a Rails schema. It uses Express.js as the web framework and TypeORM for database interactions with PostgreSQL.

## Setup

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Configure the database connection in `src/ormconfig.ts`.

4. Run the application:
   ```
   npm run dev
   ```

5. The server will start on port 3006.

## Folder Structure

- `src/controllers/`: Contains RESTful controllers for each resource.
- `src/models/`: Contains TypeORM models for each table in the schema.
- `src/services/`: Contains service classes for business logic and database transactions.
- `src/helpers/`: Contains utility functions shared across controllers and services.
- `src/types/interfaces/`: Contains TypeScript interfaces for models, request bodies, and responses.
- `src/types/constants/`: Contains application-wide constants.

## Technology Stack

- Node.js
- TypeScript
- Express.js
- TypeORM
- PostgreSQL

## Features

- Models with relationships and validations.
- RESTful controllers with standard CRUD operations.
- Services for business logic.
- Helpers for utility functions.
- TypeScript interfaces and constants.
